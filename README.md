# 🌐 Portfólio Pessoal – Monique Silva

Site de portfólio responsivo com apresentação, especialidades, projetos e certificações. Feito com **HTML, CSS e JavaScript puros**, sem frameworks, e pronto para publicar no **GitHub Pages**.

## ✨ Funcionalidades
- Layout responsivo (desktop e celular)
- Tema claro/escuro com preferência salva
- Lista de projetos carregada de um array em JavaScript, fácil de atualizar
- Menu fixo com rolagem suave

## 🧰 Tecnologias
HTML5 · CSS3 (Flexbox/Grid, variáveis CSS) · JavaScript (ES6)

## 🚀 Como publicar no GitHub Pages
1. Vá em **Settings → Pages** neste repositório
2. Em *Source*, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`
3. Salve. Em cerca de 1 minuto o site fica em `https://moniquesilva79.github.io/portfolio-site/`

## 🛠️ Como personalizar
- Textos: `index.html`
- Cores: variáveis no topo de `style.css`
- Projetos: array `projects` em `script.js`
